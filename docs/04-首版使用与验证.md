## 版本与环境

- 版本：0.0.1（开发中；未发布 npm、无 Release）。
- 声明平台：Windows x64 + Node.js 24.x + Git；本轮实际验证于 Windows 11 + Node 24.x + 本机 Chrome + 本机 Git。
- 自动化基线（截至 2026-11-15 第三轮）：`npm run lint`、`npm run typecheck`、`npm run build` 通过；`npm test` 15 个文件 75 项通过；`SPECMILL_TEST_CHROME` 指向本机 Chrome 时 `npm run test:e2e` 16 项通过；`npm run verify:package` 通过（离线缓存安装）。

## 使用步骤

安装、启动、停止、重启、数据目录与凭据见 [README](../README.md)。基本流程：创建项目 → 登记工作区 → 建变更 → 冻结基线 → 写会话中保存点 → （需要时）生成固定交接 → 提交执行证据与目标 → 审阅批量确认/豁免/处置 → 完成验收 → 导出恢复包（随时可导）。完整命令清单见交接文档。

## 容量与性能

- 默认每项目记录预算 20 MiB（含附件字节、活跃会话预留）；80% 起预警；超限写入 413 原子拒绝，读取与完整导出不受阻；操作状态（导出/恢复）不占预算。
- 近上限恢复往返（预警区）已验证记录投影逐字节一致；内存与耗时未做专项测量（未执行）。

## 能力边界（明确未提供）

- 工作台记录与受管理附件不是源码备份；恢复包不含源码、未提交差异正文、依赖、运行环境或任何凭据。
- 未提供：分包导出、历史清理、跨变更冲突自动检测、多项目合并恢复。
- 凭据边界：登录口令与浏览器会话随进程重启失效；写会话授权不经包导出。
- 未发布：npm 发布、GitHub Release、自动推送均不在本版动作内。
