# Domain Docs

SpecMill is a single-context repository. Before exploring a domain area, read the root `GLOSSARY.md` and relevant decisions in `docs/adr/`.

Use the glossary's terms in issues, designs and implementation discussions. When a term is missing, consider whether a real domain gap should be recorded with the domain-modeling skill.

If a proposal conflicts with an ADR, identify the conflict explicitly and explain whether the decision should be revisited. Create new terms and ADRs only when a decision or distinction warrants them.
