# 切片 A 实施计划

对应 [团队工作流设计](../../05-团队工作流设计.md)。以一个固定的订单日期筛选需求验证真实 Agent 调度，无新增生产依赖。仅显式启用的本机服务注册试点路由，数据与 v0.1 项目恢复包分开。

1. 在 server/pilot 下实现事务状态机和进程调度。冻结后方可领取，回执支持安全重放，每次尝试有唯一授权代次。Worker 中断后回收并重派，过期结果不可推进。验收归档保存基线、尝试、提交、SQL、逐条件测试和人工决定。
2. 独立 Worker 调用已安装的编码 Agent CLI，只提供固定合成数据模型和审阅意见，工具关闭。将 SQL 写入独立样例仓库，提交后从提交对象读回，在内存数据库运行固定测试。限制代码、进程时长和重试次数。
3. 本机用户在 Web 中创建、冻结、审阅证据、退回或验收并下载归档。Agent 凭据不可执行人工决定。区分等待、失败、恢复及请求结果未知。
4. 用隔离数据覆盖重复命令、过期决定、未通过测试、Worker 强制终止、服务重启和迟到写回。单独运行真实 Agent 并留存可核对的样例摘要；完成构建、相关回归及浏览器验证后更新 README 并推送 main。
