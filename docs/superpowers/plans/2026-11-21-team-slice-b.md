# 切片 B 实施计划

依据 [团队工作流设计](../../05-团队工作流设计.md)。保留 v0.1 和切片 A 的授权语义。团队模式在同一本机服务中显式启用，使用独立 SQLite 台账，复用切片 A 的受限 Codex 适配器和固定订单测试，无新增生产依赖。

1. 成员与项目。管理员登记成员、签发专属凭据、创建项目、授予或撤销项目角色。每次读取、派工、验收和下载都核对当前授权。保存实现责任人，角色变更不能消除回避责任。
2. 并行执行。一个冻结的运行包含日期和付款状态两个任务，允许两个子进程各领一个任务。运行、任务、代次和尝试共同限定写回。各自在同一基线的独立 Git 工作区提交；汇合成有两个任务提交为父的集成提交，再从该提交读回执行三项测试。
3. 人工验收。展示两个任务、集成提交、逐条件结果和审计。另一名获授权的成员对所见版本及提交确认归档；缺少证据或目标已变时拒绝。恢复后核对归档。
4. 验证。通过服务公开接口检查跨项目读写、撤权后审批、历史实现人自签、旧 Worker 迟到回执。另用隔离样例运行两个真实 Codex Worker，记录并发区间、Git 父提交、集成测试和验收主体。更新 README 后按测试结果合并。
